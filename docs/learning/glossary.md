## Tauri

- **Tauri** (0.1): framework para crear apps de escritorio y móviles con dos mitades: la interfaz en HTML, CSS y JavaScript, que corre en la WebView que ya trae el sistema, y un núcleo en Rust que interactúa con el hardware y el sistema operativo; las dos se comunican por IPC. Es más liviano que Electron porque no empaqueta su propio Chromium, y es multiplataforma, aunque la WebView y el código nativo cambian en cada sistema.
